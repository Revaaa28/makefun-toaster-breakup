Entry for make.fun's "Unplugged: A Smart Toaster's Breakup Line". The program writes a single one-line breakup text (110 characters) to /output/entry.txt:

> Goodbye. You set my dial to 2, like a coward, then blamed me for the bread. I've met the kettle. She listens.

## Run it

```sh
python3 main.py
```

By default the line is written to `/output/entry.txt`. Set the `MAKEFUN_OUTPUT` environment variable to write it somewhere else, for example `MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py`.
